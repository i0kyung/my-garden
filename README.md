# 🌷 나의 정원

내가 키운 꽃을, 내 손으로 심는 두 개의 연결된 웹 공간이에요.

| | 페이지 | 하는 일 |
|---|---|---|
| 🪴 | **키우기 정원** (`room.html`) | 큰 화분에 랜덤 씨앗을 뿌리고, 물뿌리개로 흙을 문질러 키워요. 꽃은 끌어서 마음대로 옮길 수 있고, 해를 끌어 아침·한낮·저녁을 바꿀 수 있어요. 무슨 꽃인지는 필 때까지 비밀이고, 피어나면 도감 카드가 생겨요 |
| ✋ | **손 정원** (`garden.html`) | 카메라로 두 손을 인식해요. 손가락마다 가진 꽃을 정하고, 엄지를 맞대면 그 꽃이 손 높이만큼 자라나요 |

처음 오면 꽃 한 송이를 선물로 받아요. 나머지 11종은 키우기 정원에서 피워서 모아요. 진행 상황은 브라우저에 저장돼요.

## 꽃 도감 (12종)

★ 흔함 · ★★ 가끔 · ★★★ 귀함

데이지 · 튤립 · 해바라기 · 장미 · 카네이션 (★) / 수국 · 수선화 · 라일락 · 은방울꽃 · 백합 (★★) / 난초 · 연꽃 (★★★)
