# 🌷 나의 정원

내가 키운 꽃을, 내 손으로 심는 두 개의 연결된 웹 공간이에요.

| | 페이지 | 하는 일 |
|---|---|---|
| 🪴 | **키우기방** (`room.html`) | 화분 8개에 물을 주고 쓰다듬으며 씨앗 → 새싹 → 줄기 → 봉오리 → 개화까지 키워요 |
| ✋ | **손 정원** (`garden.html`) | 카메라로 두 손을 인식해요. 엄지를 손가락 끝에 맞대면 그 손가락의 꽃이 손 높이만큼 자라나요 |

키우기방에서 피운 꽃만 손 정원에서 심을 수 있어요. 진행 상황은 브라우저에 저장돼요.

## 손가락과 꽃

| | 검지 | 중지 | 약지 | 새끼 |
|---|---|---|---|---|
| 왼손 | 튤립 | 장미 | 데이지 | 은방울꽃 |
| 오른손 | 해바라기 | 백합 | 수국 | 라일락 |

## 테스트용 주소

- `room.html?fast` : 20배 빠르게 자라요
- `garden.html?all` : 8종을 모두 열어요

## 만든 도구

Three.js · MediaPipe Hand Landmarker · 3D 꽃 모델(Meshy AI)
